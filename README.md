# 🏯 Изучение японской каны (Kana Learning App)
Web-приложение для изучения хираганы, катаканы.


Интерактивное веб-приложение и Android-клиент для изучения и тренировки японских слоговых азбук — **Хираганы**, **Катаканы** и сочетаний **Ёон** — с озвучкой, гибкими настройками сложности и кастомизацией интерфейса.

## ✨ Возможности приложения

* **Три режима практики:**
  * **Кана → Ромадзи** — определение чтения по символу.
  * **Ромадзи → Кана** — подбор правильного символа по его чтению.
  * **Слова (кана → ромадзи)** — чтение целых слов с настройкой длины (от 2 до 6+ символов).
* **Гибкий выбор алфавита:** тренировка только Хираганы, только Катаканы, обоих алфавитов сразу или выборочных групп символов (включая Ёон).
* **Интерактивная таблица каны:** удобный справочник для быстрого повторения всех символов Хираганы, Катаканы и Ёон.
* **Озвучка произношения:** встроенные аудиофайлы для запоминания правильного звучания.
* **Статистика прогресса:** отслеживание количества правильных ответов, общего числа попыток и процента точности.
* **Гибкая кастомизация интерфейса:**
  * **Темы оформления:** системная, светлая и тёмная.
  * **Цветовые палитры:** Фиолетовая, Океан, Закат, Лес или выбор собственного цвета.
  * **5 японских шрифтов:** *Noto Sans JP*, *Noto Serif JP*, *Zen Kaku Gothic New*, *Zen Maru Gothic* и рукописный *Kosugi Maru*.

## 📱 Установка и запуск

### 1. Веб-версия (в браузере)
Приложение работает без установки на любом устройстве:
👉 **[Открыть Kana Learning App](https://vxmitbxy.github.io/kana-learning-app/)**

### 2. Android-приложение (APK)
Для смартфонов на Android доступна автономная WebView-сборка:
1. Перейдите в раздел **[Releases](https://github.com)**.
2. Скачайте файл **`kana.apk`**.
3. Установите приложение на устройство (при необходимости разрешите установку из неизвестных источников).

## 🛠 Технологии

* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Шрифты:** Google Fonts (Noto Sans/Serif JP, Zen Kaku/Maru Gothic, Kosugi Maru)
* **Мобильная версия:** Android WebView
